# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be patient with newcomers, criticise code and ideas
rather than people, and no harassment of any kind. This applies to issues, pull
requests, discussions and any other project space.

If someone's behaviour is a problem, contact the maintainer privately through
their GitHub profile ([@PandhuWibowo](https://github.com/PandhuWibowo)).
Reports are kept confidential. Maintainers may edit or remove contributions and
may block people who do not follow this code.
